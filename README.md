# PyEEM

Modular EEM (Excitation-Emission Matrix) preprocessing library for biomedical spectroscopy.

## Installation

```bash
pip install pyeem
```

For development:

```bash
git clone https://github.com/your-username/PyEEM.git
cd PyEEM
pip install -e ".[dev]"
```

## Usage

```python
import pyeem

print(pyeem.__version__)
```

## Requirements

- Python >= 3.9
- NumPy >= 1.22
- SciPy >= 1.8
